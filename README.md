# Adarsh Pachat — portfolio

The portfolio is a standalone `index.html` with inline CSS and JavaScript. It uses three.js and Google Fonts from external CDNs. For local preview, run `python -m http.server 5176` in this folder and open `http://localhost:5176`.

The GitHub Actions workflow copies `index.html` into `dist` and deploys it to GitHub Pages when `main` changes. The portfolio folder is the root of the GitHub repository.
