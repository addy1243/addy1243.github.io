# Adarsh Pachat — portfolio

React, Vite, TypeScript and Tailwind portfolio. Run `npm install` followed by `npm run dev` for local development, or `npm run build` for a production build.

## GitHub Pages

Push this directory to a GitHub repository with `main` as its default branch. In the repository's Settings → Pages, select **GitHub Actions** as the build and deployment source. The included workflow builds and deploys on each push to `main`. The relative Vite base supports both a user site and a repository site.

The background video and Google Fonts are externally hosted and require a network connection.
